# Мок-сервер CoffeeRun (Mockoon)

Контракт API — [docs/openapi.yaml](../docs/openapi.yaml). Этот мок отвечает по нему.

## Запуск

1. Установить [Mockoon](https://mockoon.com/download/) (десктоп).
2. **Open local environment** → `mock/coffeerun.json` → ▶ Start. Порт 3000.
3. Адрес сервера:
   - с компьютера — `http://localhost:3000`;
   - с эмулятора Android — `http://10.0.2.2:3000`.

Фото позиций лежат в `mock/images/` и отдаются по `GET /images/<id>.jpg`.

## Демо-данные

- Аккаунт: телефон `+79990000000`, пароль `coffee123`. Занятый телефон для регистрации — тот же.
- Токен у всех один: `demo-token`. Защищённые запросы без `Authorization: Bearer demo-token` получают 401.
- Мок на одного пользователя: зарегистрированный пользователь не войдёт по своему паролю, вход работает только для демо-аккаунта.
- Перезапуск окружения (Stop → Start) сбрасывает профиль, избранное и заказы к исходным.
- Меню на двух языках: `Accept-Language: en` — хранилище `menu_en`, иначе `menu_ru`. Тексты позиций правятся там.

## Как показать ошибки

| Что | Как |
|---|---|
| 500 у меню | Маршрут `GET /menu` → ответ «Ошибка сервера» → флажок **Set as default** |
| Загрузка меню | Ответ 200 у `/menu` уже с задержкой 1,5 с |
| 409 при заказе | В меню кокосовое молоко отмечено «нет в наличии», и приложение не даст его выбрать. Чтобы показать 409: **Data** → `menu_ru` (и `menu_en`) → у `COCONUT` поставить `"available": true` → перезапустить приложение (меню грузится раз за запуск) → оформить напиток с кокосовым. Сервер ответит 409: «в меню было, а на кухне закончилось» |
| 401 | Вход с неверным паролем |
| Нет сети | Остановить Mockoon (Stop) |
