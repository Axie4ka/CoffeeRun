# Repeat Order Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Повторять исторический заказ по актуальным товарам, опциям и ценам через один use case.

**Architecture:** MenuSnapshot связывает товары с ценами одного ответа; use case валидирует рецепт и применяет добавления только для исходной сессии. ViewModel остаются с UI-защитой нажатия и преобразованием результата.

**Tech Stack:** Kotlin, coroutines, существующий Retrofit; без новых зависимостей.

**Spec:** `docs/superpowers/specs/2026-11-10-repeat-order-design.md`

## Global Constraints

- feature/favorites-coordinator, без commit/push/merge.
- Сохранить историю, текущую корзину при ошибке и защиту сессии.
- Не заменять рецепт молча; не использовать stale cache при неудачном refresh.

## Review Focus

- Товары и цены взяты из одного ответа при смене языка/обновлении.
- Отсутствующая опция не получает нулевую доплату и не заменяется дефолтом.
- Закрытие экрана/смена входа до ответа не добавляет строки поздним результатом.
- Переполнение лимита количества не выдаётся за полное добавление.
- Оба экрана используют один сценарий, а объяснение не теряется при навигации.
