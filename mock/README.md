# Мок-сервер CoffeeRun (Mockoon)

Контракт API — [docs/openapi.yaml](../docs/openapi.yaml). Этот мок отвечает по нему.

## Запуск

1. Установить [Mockoon](https://mockoon.com/download/) (десктоп).
2. **Open local environment** → `mock/coffeerun.json` → ▶ Start. Порт 3000.
3. Адрес сервера:
   - с компьютера — `http://localhost:3000`;
   - с эмулятора Android — `http://10.0.2.2:3000`.

Фото позиций лежат в `mock/images/` и отдаются по `GET /images/<id>.jpg`.

## Демо-данные

- Аккаунт: телефон `+79990000000`, пароль `coffee123`. Занятый телефон для регистрации — тот же.
- Мок использует один аккаунт `mockoon-demo` с токеном `demo-token`. Защищённые запросы без `Authorization: Bearer demo-token` получают 401.
- Мок на одного пользователя: зарегистрированный пользователь не войдёт по своему паролю, вход работает только для демо-аккаунта.
- Перезапуск окружения (Stop → Start) сбрасывает профиль, избранное и заказы к исходным.
- Меню на двух языках: `Accept-Language: en` — хранилище `menu_en`, иначе `menu_ru`. Тексты позиций правятся там.
- Аватар и рецепты доступны двум клиентам одного запущенного окружения. Они хранятся в `demoAvatar` и `demoRecipes` одного демо-аккаунта. Перезапуск мока сбрасывает эти данные.
- Расписание кофеен находится в `shopSchedules` обоих языковых меню. Московская готовит заказ за 12 минут, Строителей — за 18 минут. Часы зависят от дня недели. Для демонстрации оформления используй время работы точки или измени часы в обоих языковых меню.
- Акции из `promotions` передаются вместе с меню. Скидка на средний капучино применяется к цене напитка выбранного размера. По акции «2+1» каждая полная тройка подходящей выпечки даёт одну бесплатную порцию из самых дешёвых. Условия и периоды в обоих меню должны совпадать.

## Как показать ошибки

| Что | Как |
|---|---|
| 500 у меню | Маршрут `GET /menu` → ответ «Ошибка сервера» → флажок **Set as default** |
| Загрузка меню | Ответ 200 у `/menu` уже с задержкой 1,5 с |
| 409 при заказе | В меню кокосовое молоко отмечено «нет в наличии», и приложение не даст его выбрать. Чтобы показать 409: **Data** → `menu_ru` (и `menu_en`) → у `COCONUT` поставить `"available": true` → перезапустить приложение (меню грузится раз за запуск) → оформить напиток с кокосовым. Сервер ответит 409: «в меню было, а на кухне закончилось» |
| 409 при отмене | Отменить можно только заказ ко времени (`ACCEPTED`). Заказ «как можно скорее» сразу `PREPARING` — на его отмену сервер ответит 409. Повторная отмена того же заказа — тоже 409 |
| 401 | Вход с неверным паролем |
| Нет сети | Остановить Mockoon (Stop) |


## Восстановление оформления

Приложение отправляет заказ через `POST /order-attempts/{uuid}`. Повтор с тем же
UUID и тем же запросом возвращает тот же номер. Изменённый запрос с прежним UUID получает 409 ATTEMPT_PAYLOAD_MISMATCH. Неверная цена или недоступная позиция получает 409 ORDER_UNAVAILABLE. Кнопка «Проверить статус заказа» вызывает
`POST /order-attempts/{uuid}/resolve`. Если заказ принят, мок возвращает его.
Если заказ ещё не создан, мок закрывает UUID и возвращает HTTP 410 даже при
последующей запоздалой отправке. Перезапуск приложения сохраняет этот сценарий.
Stop → Start самого Mockoon сбрасывает всю демо-базу, включая ключи.

HTTP smoke test (Node.js 18+): `node mock/check-checkout.mjs` from the repository root. It creates demo orders. Restart the Mockoon environment to reset them.

Команда `node mock/check-personalization.mjs` проверяет сохранение, чтение и удаление рецептов и аватара, а также обещанное время готовности. Обе команды принимают адрес Mockoon вторым аргументом, например `http://127.0.0.1:3137`.

Для демонстрации синхронизации запустите отдельный экземпляр этого окружения на порту 3137 и Android-эмулятор. Следующая команда запускает на эмуляторе два Android-клиента с отдельными сессиями, файлами и базами Room. Первый меняет рецепт, второй переименовывает свою устаревшую копию. Затем клиенты проверяют удаление рецепта и передачу JPEG через общий аккаунт.

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest '-Pandroid.testInstrumentationRunnerArguments.class=ru.coffeerun.SharedMockoonPersonalizationTest' '-Pandroid.testInstrumentationRunnerArguments.mockoonBaseUrl=http://10.0.2.2:3137/'
```
